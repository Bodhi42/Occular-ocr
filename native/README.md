# occular-decode — нативный (Rust) декодер

Ускоритель декода для Occular-OCR: CTC prefix beam search + 4-граммная LM на Rust вместо
чисто-питоновского пути. Текст выдаёт **тот же самый** (проверено построчно, паритет байт-в-байт),
но декод быстрее в 5–13 раз на строку и в 17–48 раз на страницу, загрузка модели — 0,7 с вместо
2,6 с при вдвое меньшем резиденте.

**Опционален.** `occular` уже умеет его использовать: если пакет `occular_decode` установлен —
подхватывает автоматически, иначе работает на чистом Python с тем же результатом. Никаких правок
библиотеки делать не нужно (в отличие от прежних версий — поддержка уже встроена в
`occular/decoder_lm.py` и `occular/recognizer_onnx.py`).

## Что внутри

```
crate/     исходники Rust-крейта (+ заготовка CI на 6 платформ в .github-workflow-wheels.yml)
wheels/    собранное колесо: abi3, Python 3.8+, manylinux_2_34 x86_64 (нужен glibc ≥ 2.34)
tools/     verify_parity.py — сверка нативного и питоновского декодеров на ваших картинках
```

## Установка

Проверить glibc:

```bash
ldd --version | head -1
```

* **glibc ≥ 2.34** (Ubuntu 22.04+, Debian 12+, RHEL 9+), x86_64 — готовое колесо:

  ```bash
  pip install native/wheels/occular_decode-0.1.0-cp38-abi3-manylinux_2_34_x86_64.whl
  ```

* **glibc старее** (Ubuntu 20.04, CentOS 7) или другая архитектура (aarch64) — собрать из исходников:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal
  source "$HOME/.cargo/env"
  pip install maturin
  cd native/crate && maturin build --release && pip install target/wheels/*.whl
  ```

  Либо один раз прогнать `native/crate/.github-workflow-wheels.yml` в CI и ставить колёса из
  артефактов — тогда на сервере компилятор не нужен.

## Проверка

```bash
python -c "from occular import ocr; print(ocr('какой-нибудь.png')[:200])"
```

В логе должно быть `[occular] LM (нативный декодер)`. Если написано `LM (чисто-Python)` — модуль
не подхватился, но всё работает по-старому.

Сверка результатов на своих файлах:

```bash
python native/tools/verify_parity.py /путь/к/сканам   # код 0 — полное совпадение, 3 — расхождения
```

## Откат

Не удаляя пакет, отключить переменной окружения:

```bash
OCCULAR_NATIVE_DECODER=0 python ...
```

Либо `pip uninstall occular-decode`.

## Что стоит знать

* Файлы модели (`compact_lm.npz`, `unigrams.txt`) отображаются в память, а не читаются в кучу.
  Страницы файловые — **общие между процессами**: при нескольких воркерах это ~270 МБ на всех, а
  не на каждого. На сетевой ФС mmap может быть медленным — тогда сработает откат на numpy-путь
  (с предупреждением), либо положите файлы на локальный диск и укажите `OCCULAR_LM_DIR`.
* `pyctcdecode` и `pygtrie` после установки нативного декодера используются только в фолбэке;
  убирать их из зависимостей не нужно — без них теряется запасной путь.
* Разбор порта и одной особенности beam-декодера, воспроизведённой ради паритета, — в `crate/README.md`.
